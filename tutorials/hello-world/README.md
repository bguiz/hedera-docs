# Hello World

Do you want to develop on Hedera, but are unsure where to start? Why not start with something you can complete in **under 10 minutes**? This guide is designed to kickstart your Hedera development journey.

Let's begin!

### What you will accomplish

There are multiple Hello World tasks available to you to complete!

* [ ] Create and fund accounts on Hedera Testnet
* [ ] Transfer HBAR from one account to another
* [ ] Create a topic and publish a message to it on Hedera Consensus Service (HCS)
* [ ] Create a fungible token using Hedera Token Service (HTS)
* [ ] Compile, deploy, and interact with an EVM smart contract using Hedera Smart Contract Service (HSCS)

To start, you **must** complete the first sequence (create and fund accounts), as you will need **funded accounts** to do any other tasks on Hedera.
